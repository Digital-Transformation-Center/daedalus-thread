The Daedalus Thread implementation is underway. The project will first target a COTS, hobby-grade aircraft, making mission-driven aerodynamic modifications. Development will begin with open-source tools through the whole stack for accessibility.

Following initial proof-of-concept generation, this phase will expand to include industry-standard proprietary tools through the stack to complete Phase 1. 

Early FreeCAD integration demonstrates highly-dynamic wing designs, capable of adapting to completely different misison requirements. Different wing designs share modular electronic and physical interfaces, while dynamically adapting to aerodynamic requirements.
