## Project Pillars

<CardGrid stagger>
  <Card title="Bi-Directional Digital Thread" icon="setting">
    Forming a complete, end-to-end digital thread that directly connects high-level SysML mission requirements to dynamic CAD parameters, physical manufacturing, and software outputs.
  </Card>
  <Card title="Real-World Toolchain Assessment" icon="laptop">
    Implementing and stress-testing commercial digital thread tools to capture data friction, software interoperability bottlenecks, and toolchain performance in real workflows.
  </Card>
  <Card title="Open MOSA Aerial Platform" icon="puzzle">
    Building a fully open-source air platform adhering to Modular Open Systems Approach (MOSA) standards, giving integration testers an affordable, customizable testbed for payloads and autonomy.
  </Card>
  <Card title="Collaborative & Workforce Platform" icon="open-book">
    Providing an expanding and evolving aerial system designed to foster community integration, collaborative research, and hands-on training for early-career engineers.
  </Card>
</CardGrid>

## Core Benchmark Metrics

| Metric | Target Goal | Project Impact |
| :--- | :--- | :--- |
| **Design Latency** | Requirement adjustment to CAD update | < 4 hours total |
| **Wing Fabrication** | MBSE design lock to physical wing | < 48 hours turnaround |
| **Digital Twin Precision** | External wing envelope comparison | ±1.5 mm tolerance |
| **NRE Hours** | Design hours vs traditional workflows | > 60% reduction |
| **Field Swappability** | Wing or payload module exchange | < 5 minutes with hand tools |
